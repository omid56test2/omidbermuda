هر کاربر می‌تواند یک یا چند Listener از ساختار Bermuda دریافت کند.

آمار واقعی مصرف پس از فعال‌سازی Xray StatsService نمایش داده می‌شود.
با ساخت، ویرایش یا حذف کاربر، فایل Xray بازسازی می‌شود و در صورت فعال‌بودن Xray، فرایند برای اعمال تغییرات Restart می‌شود. سهمیه حجمی با آمار Xray اعمال می‌شود. IP، جریان‌های هم‌زمان و نرخ تبادل داده در Gateway برای هر مسیر اختصاصی کاربر کنترل می‌شوند؛ برای IP واقعی پشت پراکسی، TRUSTED_PROXY_CIDRS را فقط با CIDR پراکسی مورداعتماد تنظیم کن.

سه Listener داخلی Bermuda

هر Listener واقعی در Xray روی loopback اجرا می‌شود و فقط مسیر متناظر از Gateway عمومی به آن Forward می‌شود.

وضعیت Xray: نامشخص
TLS در لبه عمومی / Reverse Proxy خاتمه می‌یابد؛ Xray فقط روی 127.0.0.1 گوش می‌دهد. این سه Listener به ترتیب VLESS/XHTTP، VLESS/WebSocket و Trojan/WebSocket هستند.

محدودیت IP و جریان هم‌زمان در لایه Gateway اعمال می‌شود. برای WebSocket هر اتصال تا پایان نشست شمرده می‌شود؛ در XHTTP شمارش بر اساس درخواست/جریان HTTP است و الزاماً برابر تعداد دستگاه‌ها نیست. کنترل سرعت یک سقف تجمیعی تقریبی برای هر کاربر در Gateway است. فایل Backup شامل اطلاعات حساس کاربران و اعتبارنامه‌هاست؛ آن را رمزگذاری‌شده نگه دار.

بازیابی خودکار Xray با XRAY_AUTORESTART=true فعال می‌شود.
